# AI Investor V1 — Paper Trading

نسخة أولية آمنة للتداول الورقي فقط.

- رأس مال تجريبي: $1,000
- أموال حقيقية: $0
- السوق المستهدف: أسهم وETF أمريكية
- لا يوجد تنفيذ تداول حقيقي
- مصمم ليكون قابلًا للنشر على منصة استضافة مجانية تدعم Streamlit

## التشغيل
```bash
pip install -r requirements.txt
streamlit run app.py
```
